# Self-Hub · 个人内容与资料中心

面向自己日常使用的个人站：集中保存笔记、网页收藏、项目资料和相关附件，同时管理服务器、凭证、续费提醒与手绘记录。

当前使用 React、TypeScript、Vite 和 Tailwind CSS，部署目标为 Cloudflare Pages 或 Vercel，支持绑定自定义域名。项目按单人使用设计，优先保证内容容易录入、找回、迁移和恢复。

## 当前能力与边界

| 模块 | 当前已有 | 仍需补齐 |
| --- | --- | --- |
| 网站收藏 | 添加、分类浏览、搜索、访问记录、HTML 书签导入（带去重） | 编辑、批量管理、项目关联 |
| 本地笔记 | 新建、编辑、文本阅读、全文匹配、草稿保护与覆盖确认，与数据互通页共用同一套 Markdown 渲染 | 附件 |
| 项目资料 | 项目实体、关联文档/站点/服务器/提醒与决策记录，跨页跳转可定位 | 统一资料归属与项目概览 |
| 服务器 | 地址、环境、SSH 命令与到期信息展示 | 真实健康检测；当前在线状态不是探测结果 |
| 凭证金库 | PBKDF2 + AES-256-GCM 加解密、30 天设备免密（IndexedDB 包裹存储）、锁定即清明文 | 说明字段与锁定清理仍需加固 |
| 提醒 | 到期列表、分类、完成标记、周期顺延、编辑 | 关闭网页后的主动提醒 |
| 签到 | 浏览器 HTTP 请求（15s 超时 + 业务结果判定）、打开目标页、用户脚本生成 | 按日统计、任务执行记录 |
| Obsidian / OSS | 完整目录树浏览（多层、分页、跨层搜索）、Markdown 阅读与三模式编辑器（分屏预览/快捷键/大纲）、GFM + 代码高亮 + `[[双链]]` + `#标签` + 标注块 + frontmatter 属性表 + 图片签名渲染、贴图自动上传、重命名/移动/新建目录/上传文件、附件预览、最近打开、失败状态如实反馈 | 覆盖保护与真实环境联调 |
| 五彩 / 有道 | 本地记录、手工录入、转为笔记或 Markdown 的入口 | 五彩抓取未接入当前视图；有道抓取仍返回缓存或示例 |
| 手绘 | 绘制、撤销、PNG 保存（空画板拦截 + 降采样） | 独立附件存储、项目关联、容量管理 |
| 全局搜索 | `Ctrl+K` / `Cmd+K`、文本匹配、点击后定位到具体条目 | 命中的完整中文/拼音检索、增量索引 |

初次打开会载入示例数据。当前主要业务数据保存在浏览器 `localStorage` 的同一个 JSON 中；换浏览器、换设备不会自动得到同一份本地数据。已有 JSON 导入导出入口，完整性、加密格式和恢复流程仍是下一批任务。

**当前版本不适合作为重要凭证或资料的唯一副本。** 主密码不会以明文落盘，"记住这台设备"通过设备密钥包裹后存于本机 IndexedDB（30 天有效，锁定即销毁）；但 IndexedDB 与 localStorage 同源，无法抵御在本源上执行脚本的攻击者。历史缺陷审计与修复记录见 [2026-10-16 审计报告](docs/AUDIT_REPORT_2026-10-16.md)。

## 希望个人站逐步存下什么

- **笔记与知识**：随手记、长文、学习记录、技术手册、命令和代码片段。
- **收藏与剪藏**：网页、工具、文章摘要、个人批注、来源链接与阅读状态。
- **项目资料**：项目说明、仓库、部署地址、需求、决策记录、操作手册与附件。
- **文件附件**：图片、截图、PDF、手绘图、原始文档；通过资料条目组织和检索。
- **资源与提醒**：服务器、域名、订阅、凭证和续费日期，并关联到对应项目。

扩展采用“公共目录字段 + 各内容类型详情 + 独立附件”的方式。普通目录、正文、附件和敏感凭证分别处理，逐步从整包读写迁移到按条目保存。技术方案见[内容扩展设计](docs/superpowers/specs/2026-10-15-personal-content-hub-design.md)。

## 本地运行

```bash
npm ci
npm run dev
```

默认开发端口为 `5173`（可用 `PORT=4000 npm run dev` 覆盖）。之所以不再用 `3000`：部分 Windows 机器把 3000 划入了系统保留端口段（`netsh interface ipv4 show excludedportrange protocol=tcp` 可查），绑定会以 `EACCES` 失败，而 Vite 只会对"端口被占用"自动换端口。

生产检查与预览：

```bash
npm run build
npm run preview
```

`build` 会运行 TypeScript 检查和 Vite 构建，产物位于 `dist/`。

回归测试（Playwright，自动拉起 dev server）：

```bash
npm run test:e2e     # 21 条端到端用例
npm run typecheck    # 仅类型检查
```

## 部署

1. 运行 `npm run build`。
2. 在 Cloudflare Pages 部署 `dist/`，或运行：

   ```bash
   npx wrangler pages deploy dist --project-name=self-hub
   ```

3. 在 Pages 项目中绑定自己的域名。
4. 为私人入口配置 Cloudflare Access 邮箱访问策略，并检查自定义域名、默认域名、预览地址及后续 API 的实际保护范围。

仓库中的部署配置和页面状态文字不能证明线上门禁已经启用。Cloudflare Access 处理访问身份，金库主密码处理应用内解密；配置门禁后仍需单独解锁金库。
