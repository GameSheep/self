# Self-Hub · 个人内容与资料中心

面向自己日常使用的个人站：集中保存笔记、网页收藏、项目资料和相关附件，同时管理服务器、凭证、续费提醒与手绘记录。

当前使用 React、TypeScript、Vite 和 Tailwind CSS，部署目标为 Cloudflare Pages 或 Vercel，支持绑定自定义域名。项目按单人使用设计，优先保证内容容易录入、找回、迁移和恢复。

| --- | --- | --- |
| 网站收藏 | 添加、分类浏览、搜索、访问记录、HTML 书签导入（带去重） | 编辑、批量管理、项目关联 |
| 本地笔记 | 新建、编辑、文本阅读、全文匹配、草稿保护与覆盖确认，与数据互通页共用同一套 Markdown 渲染 | 附件 |
| 项目资料 | 项目实体、关联文档/站点/服务器/提醒与决策记录，跨页跳转可定位 | 统一资料归属与项目概览 |
| 服务器 | 地址、环境、SSH 命令与到期信息展示、**真实 HTTP 健康探测（在线 / 不可达 / 未探测，带延迟与检测时间）** | 端口级 TCP 检测（浏览器限制）与告警通知 |
| 凭证金库 | PBKDF2 + AES-256-GCM 加解密、30 天设备免密（IndexedDB 包裹存储）、锁定即清明文 | 说明字段与锁定清理仍需加固 |
| 提醒 | 到期列表、分类、完成标记、周期顺延、编辑、**到期/逾期通知（扩展内由后台 Service Worker + alarms 驱动，关掉标签页也会提醒；网页版仅在页面打开时提醒）** | 系统级原生推送（需桌面端）、多设备同步提醒状态 |
| 签到 | 浏览器 HTTP 请求（15s 超时 + 业务结果判定）、打开目标页、用户脚本生成、**按日打卡记录与推导连续天数、近 14 天状态条** | 定时自动执行、失败重试 |
| Obsidian / OSS | 完整目录树浏览（多层、分页、跨层搜索）、Markdown 阅读与三模式编辑器（分屏预览/快捷键/大纲）、GFM + 代码高亮 + `[[双链]]` + `#标签` + 标注块 + frontmatter 属性表 + 图片签名渲染、贴图自动上传、重命名/移动/新建目录/上传文件、附件预览、最近打开、**保存冲突检测**、**删除进回收站可恢复**、**全库全文搜索（正文/标签/双链）与反向链接**、失败状态如实反馈 | 多端并发自动合并与真实环境长期联调 |
| 五彩 / 有道 | 本地记录、手工录入、转为笔记或 Markdown 的入口 | 五彩抓取未接入当前视图；有道抓取仍返回缓存或示例 |
| 手绘 | 绘制、撤销、PNG 保存（空画板拦截 + 降采样） | 独立附件存储、项目关联、容量管理 |
| 数据安全 | 一键导出/导入 JSON、加密导出（AES）、操作前回滚快照、IndexedDB 兜底、**全量状态自动备份到 OSS（`.selfhub/state.json`，5 秒防抖，冲突时另存副本而不覆盖）、从云端一键恢复** | 多设备实时双向合并（当前为快照级备份/恢复） |
| 全局搜索 | `Ctrl+K` / `Cmd+K`、文本匹配、点击后定位到具体条目、**命中笔记正文（本地全文索引）并可直接跳转**、**索引管理（篇数/字数/存储用量、更新/重建/清除、损坏自愈）** | 完整中文拼音检索、跨设备索引同步 |

| 数据安全 | 一键导出/导入 JSON、加密导出（AES）、操作前回滚快照、IndexedDB 兜底、全量状态自动备份（OSS 或 WebDAV，5 秒防抖，冲突时另存副本而不覆盖）、从云端一键恢复、**备份前剥离全部凭据（密钥/密码/Token 永不上云，恢复时用本机凭据）** | 多设备实时双向合并（当前为快照级备份/恢复）；两套同步路径尚未统一 |
| 可配置性 | **功能开关**：收件箱/项目/文档/手绘/服务器/金库/签到/五彩/有道可关闭，关闭后从导航与仪表盘消失、数据保留、随时恢复；核心模块（仪表盘/网站/倒计时/Obsidian）不可关闭 | 自动推荐该关哪些 |
| 同步一致性 | 应用设置内可直接查看扩展自带同步的状态（提供商/写入目录/目标/上次同步），两套同步同时启用时给出**重复写入警示**，并提供一键关闭扩展同步；非扩展环境明确说明不适用 | 完全合并为单一同步通道 |
| 隐私边界 | **AI 分拣默认只用本机离线规则，全程不联网**；需显式开启云端 AI，开启后发送前**自动遮蔽密钥/密码/令牌/私钥/连接串**并展示遮蔽报告，模型只见占位符，入库时本机还原真实值；导出明文备份前确认其中含凭据 | 语义级识别（当前为高置信度模式匹配） |
| WebDAV | InfiniCLOUD / TeraCloud / Nextcloud 等，PROPFIND 连接诊断（401/403/404/CORS 分别归因）、自动建目录、备份与恢复 | 跨域直连（多数 WebDAV 服务器无 CORS 头，需在扩展环境使用） |

初次打开会载入示例数据。业务数据保存在浏览器 `localStorage`，但**配置阿里云 OSS 或 WebDAV 后会自动把全量状态备份出去**（OSS: `<prefix>.selfhub/state.json`；WebDAV: `<目录>/state.json`），可在另一台设备上「从云端恢复」。冲突处理是"不覆盖 + 另存副本"，不是自动合并。已有 JSON 导入导出入口。

**当前版本不适合作为重要凭证或资料的唯一副本。** 主密码不会以明文落盘，"记住这台设备"通过设备密钥包裹后存于本机 IndexedDB（30 天有效，锁定即销毁）；但 IndexedDB 与 localStorage 同源，无法抵御在本源上执行脚本的攻击者。历史缺陷审计与修复记录见 [2026-10-16 审计报告](docs/AUDIT_REPORT_2026-10-16.md)。

## 希望个人站逐步存下什么

- **笔记与知识**：随手记、长文、学习记录、技术手册、命令和代码片段。
- **收藏与剪藏**：网页、工具、文章摘要、个人批注、来源链接与阅读状态。
- **项目资料**：项目说明、仓库、部署地址、需求、决策记录、操作手册与附件。
- **文件附件**：图片、截图、PDF、手绘图、原始文档；通过资料条目组织和检索。
- **资源与提醒**：服务器、域名、订阅、凭证和续费日期，并关联到对应项目。

扩展采用“公共目录字段 + 各内容类型详情 + 独立附件”的方式。普通目录、正文、附件和敏感凭证分别处理，逐步从整包读写迁移到按条目保存。技术方案见[内容扩展设计](docs/superpowers/specs/2026-10-15-personal-content-hub-design.md)。

## 本地运行

```bash
npm ci
npm run dev
```

默认开发端口为 `5173`（可用 `PORT=4000 npm run dev` 覆盖）。之所以不再用 `3000`：部分 Windows 机器把 3000 划入了系统保留端口段（`netsh interface ipv4 show excludedportrange protocol=tcp` 可查），绑定会以 `EACCES` 失败，而 Vite 只会对"端口被占用"自动换端口。

生产检查与预览：

```bash
npm run build
npm run preview
```

`build` 会运行 TypeScript 检查和 Vite 构建，产物位于 `dist/`。

回归测试（Playwright，自动拉起 dev server）：

```bash
npm run test:e2e     # 21 条端到端用例
npm run typecheck    # 仅类型检查
```

## 部署

1. 运行 `npm run build`。
2. 在 Cloudflare Pages 部署 `dist/`，或运行：

   ```bash
   npx wrangler pages deploy dist --project-name=self-hub
   ```

3. 在 Pages 项目中绑定自己的域名。
4. 为私人入口配置 Cloudflare Access 邮箱访问策略，并检查自定义域名、默认域名、预览地址及后续 API 的实际保护范围。

仓库中的部署配置和页面状态文字不能证明线上门禁已经启用。Cloudflare Access 处理访问身份，金库主密码处理应用内解密；配置门禁后仍需单独解锁金库。
