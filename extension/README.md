# Self-Hub 浏览器扩展包 (Chrome / Edge Manifest V3)

> **自研无感替代 五彩 (Wucai) 与 GoTab**
> 100% 本地运行 · 零云端依赖 · 零明文上传 · 强力 Obsidian 同步

| :--- | :--- | :--- |

## 🚀 安装与加载方式 (30秒即可启用)

1. 打开 Chrome 或 Edge 浏览器；
2. 在地址栏输入并访问扩展管理页：
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
3. 开启右上角 **「开发者模式 (Developer mode)」** 开关；
4. 点击左上角 **「加载已解压的扩展程序 (Load unpacked)」**；
5. 选择本项目根目录下的 **`extension/`** 目录；
6. 加载成功！立即打开一个新标签页，或者打开任意文章网页开始划线！

---

## ⌨️ 快捷操作说明

- **网页划线**：鼠标选中网页任意文字，会自动浮现 5 色划线工具条；或直接按下 **`Alt + H`** 极速高亮。
- **添加思考批注**：点击划线文本，在弹出的黑色悬浮卡片中输入你的思考与知识笔记。
- **Obsidian 增量导出**：点击浏览器右上角 Self-Hub 图标展开侧边栏，点击 **「导出 Markdown」**，自动生成 Obsidian 兼容的双链笔记并存入本地。
- **快捕到统一收件箱**：在网页任意处右键选择 **「将当前网页保存至统一收件箱」**，即可在 Self-Hub 主工作台无缝分拣。
