# Self-Hub 功能重组方案（2026-10-19）

> 目标：把"功能很混乱"改成"每一屏只做一件事"。以下每条对应你列的一项，写清楚**改成什么、数据怎么存、怎么验收**。
> 本文件是实施依据；完成情况记在 `docs/SELF_HUB_PROGRESS.md`。

## 0. 总原则

1. **父级分组不可点击**：`资源与安全 / 工具 / 资料库` 只作为标题，点不到任何页面；只点具体功能（服务器、域名、凭证、签到、手绘…）。
2. **一屏一个来源**：每个页面只看自己相关的内容与配置，不再"进来先看别的东西"。
3. **不怕重复存**：同一个信息允许在服务器、域名、凭据里各存一份；不做"必须关联到唯一来源"的限制。
4. **开关只控制入口与列表**：关掉不看的东西，不删数据（已实现）。

## 1. 首页

- **保留**现在的 常用网站 / 快速记录 / 继续工作 / 今天要处理 / 资源摘要。
- **新增中部搜索框**：输入即搜**全部数据**（笔记、批注、远端笔记、网站、服务器、域名、凭据、项目、提醒），结果按类型分组，回车/点击跳转到对应条目。
  - 与 ⌘K 的区别：首页搜索是"常驻、可直接打字"，⌘K 是全局快捷键；两者共用同一个搜索索引与结果组件，避免两套行为。
  - 搜索**不受开关过滤**（"我东西呢"兜底），与第 44 批的决定一致。

## 2. 快捷导航

- 继续作为"所有网页"的集合。
- **AI 识别自动填充**：页面提供"粘贴识别"入口（输入框 + 拖入/粘贴）。粘贴一段文字或网址后：
  1. 自动提取候选：标题、URL、分类、图标域名；
  2. **弹窗确认**：展示识别结果，并让用户选择**存到哪里**（快捷导航 / 资料库笔记 / 收件箱 / 项目）与目标分组；
  3. 确认后才写入。识别失败时保留原文，允许手工改。
- 复用现有的 AI 整理逻辑（`lib/aiIngest` / 本地规则兜底），不新写一套解析器。

## 3. 资料库

三个页签，语义互不重叠：

| 页签 | 用途 | 关键约束 |
| --- | --- | --- |
| **笔记** | 直接粘贴、直接写 | **没有"新建笔记"按钮**：进来就是一个大 textarea，粘贴即编辑，自动保存草稿 |
| **网页批注** | 只展示从别处划词存进来的内容 | 只读列表 + 修改 + 删除 + **打开原始链接**；不在这里"新建" |
| **远端笔记** | 远端（OSS / 五彩 / 有道）内容 | 名字不带 OSS；每个 tab 只显示自己的配置与文件；文件只**修改/删除**，不提供新建 |

- **3.1 全部资料删除**：跨类型混合列表正是"混乱"的来源，取消该视图；每类内容到自己的页签。
- **3.4 每 tab 只看自己**：连接参数（Bucket/Endpoint/Token…）各自出现在自己的 tab 内，不再跳到设置里的统一卡片才看得到；设置里的连接卡片保留（它是"保存/测试/启用"的唯一入口），但页面内显示只读摘要 + "去修改"。
- 文件操作收敛为"修改内容 / 删除"，上传与新建入口暂时移除（用户要求）。

## 4. 项目

- 从"多视图 + 关联资料"简化为：**项目名 + 一块大文本**（Markdown），直接存。
- 原来的关联、状态、进度列表**不再作为主界面**；需要时在文本里自己写。
- 数据兼容：`projects[].description` 继续作为这块文本的存储字段，旧数据原样显示。

## 5. 提醒

- 不改。

## 6. 资源与安全（父级不可点）

- **6.1 服务器**：在现有 SSH/健康探测之外，增加可自由记录的字段（键值对"备注项"）：SSH 端口/跳板映射、面板地址、续费日期、账号说明等。**允许与域名/凭据重复**。
- **6.2 域名（这是 bug）**：现在点"域名"会走到提醒页并显示"新建到期提醒"。改为：
  - 新增独立集合 `domains`：`name`、`startAt`（开始/购买时间）、`expireAt`（到期）、`registrar`（在哪买的）、`dns`（可选的 DNS 服务器/记录摘要）、`note`、`url`。
  - 页面只列域名自己的信息，**不再跳提醒页**；到期提醒仍可由开关选择是否在首页"今天要处理"里出现（复用现有提醒机制，但域名页不再依赖它）。
  - 迁移：把现有 `category: 'domain'` 的提醒**导入**为域名记录（保留原提醒，不删）。
- **6.3 凭据**：增加 `website`（所属网站）字段；**同一网站允许存在多条凭据**（不做唯一约束），列表按网站分组显示。

## 7. 工具（父级不可点）

- **7.1 签到**：以"支持的站点"为清单（来自你给的签到项目），**未配置的站点不显示**；配置后才出现并可执行。
- **7.2 手绘**：
  - 画布更大（占满可用区域，不再固定小尺寸）；
  - 增加形状工具：**矩形、椭圆/圆、直线、箭头**，可拖拽绘制、选中后移动/删除；
  - 保留画笔/橡皮/颜色/撤销，导出图片。
