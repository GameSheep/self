# 五彩与 GoTab 替代实施路线

更新日期：2026-10-15。状态：全部阶段待实施。本轮只有设计文档，没有替代插件成品，也没有迁移真实账号数据。

**当前主线**：电脑网页划线、批注、搜索、Obsidian 自动同步，加上 GoTab 的分组导航和新标签页。详细边界、架构与数据规则见[替代设计](superpowers/specs/2026-10-15-browser-workspace-replacement-design.md)。

- [N01–N03](NEXT_STEPS.md)：继续优先处理金库、保存失败和备份恢复。
- N06 与 N04：修正常用编辑 / 定位，建立按条目保存的 IndexedDB 底座。
- 新增浏览器划线与导航工作优先进入 R2，扩展不再排到旧路线图 M4。
- N05 的 OSS 真实性修复仍需做；R3 增加 API / D1 后，结构化资料同步通过 API，OSS 负责附件和备份。

- N09 的大附件与 N10 的完整同步能力按 R3 / R6 拆分，避免同时维护两套同步协议。

## R0 · 旧数据迁移准备

**产出**：来源清单、只读原始备份、字段覆盖表与迁移计数。由用户提供实际导出文件后实施，不假定当前账号的权限和到期时间。

- [ ] 五彩：在现有导出 / 同步权限可用时取得原始导出，另存已同步到 Obsidian 的完整独立目录。
- [ ] 核对页面、划线、批注、标签、时间和全文剪藏；只有 URL 的条目不算原文已备份。
- [ ] GoTab：保留 JSON 备份；额外 HTML 书签只作为链接兜底。
- [ ] 记录分组、文件夹、网址、排序、搜索引擎和可用图标 / 壁纸的数量。
- [ ] 原始备份保存在用户数据目录，不提交到 GitHub；开发只使用脱敏样本。

**完成标准**：原文件可离线打开，来源数量可核对；不能导出的字段有明确清单，没有把取消订阅视为取得导出文件的前提。

## R1 · 可靠底座与风险原型

**产出**：可恢复的本地资料层、共享格式，以及能验证的几个小原型。

- [ ] 完成 N01–N03、N06 和 N04 中支撑录入的核心工作，不扩大现有安全缺口。
- [ ] 明确 WebPage、Annotation、Bookmark、ImportBatch、revision 与 outbox 的格式和运行时校验。
- [ ] 划线原型：跨节点、重复文本、页面改版后重新定位；检查孤立 / 歧义记录，不错误附着。
- [ ] MV3 原型：content script、CSS 高亮绘制、站点权限、侧边栏、后台停止后任务恢复。
- [ ] Obsidian 原型：生成一页 Markdown，重复更新管理区，同时保护用户补充段落。
- [ ] 新同步服务先明确管理端与设备路由的身份校验，不把扩展 token 当成 Cloudflare Access 凭证。

**完成标准**：固定测试页面和临时 Obsidian 库中的原型均可重复演示；底座写入失败、中断迁移和恢复有明确结果。原型验证不使用真实金库或改动真实 Obsidian 文件。

## R2 · 浏览器本地替代版

**产出**：可加载的 Chrome / Edge 扩展包；单机不连接云端也能使用。

- [ ] newtab：分组、文件夹、拖拽排序、置顶、链接编辑、搜索引擎、主题与本地壁纸。
- [ ] GoTab JSON / 书签导入：预览映射、重复候选、未知字段和失效资源；导入可撤销。
- [ ] 网页划线：工具条、颜色槽、快捷键、批注、标签、项目引用、修改 / 删除与撤销。
- [ ] 自动恢复按授权站点启用；未授权站点可点击扩展临时启用。
- [ ] side panel：本页划线、整页笔记、定位与状态；集中列表支持全文检索和来源跳转。
- [ ] IndexedDB 持久化与完整本地备份；保存、待同步与失败分别展示。
- [ ] 五彩历史导入器先以真实导出样本开发；无法定位的旧摘录保留可检索副本。

**完成标准**：断网完成划线 → 批注 → 刷新 → 定位 → 搜索 → 导出；同页相同文字不会绑定错位置；链接分组与排序在浏览器重启后保留。此阶段可替代 GoTab 的已确认核心范围，尚未满足五彩的 Obsidian 自动同步条件。

## R3 · 自部署资料库与同步服务

**产出**：网页管理端、Worker API、D1 与现有 OSS 的可配置部署方式。

- [ ] D1 保存结构化资料、版本、操作幂等结果与按序变更；OSS 保存快照、附件和加密备份。
- [ ] API 验证 baseRevision，用事务提交版本与游标；失败保留本地 outbox，重复提交不重复记录。
- [ ] 设备配对、有限权限、到期、撤销、跨域与 host permission 流程完整。
- [ ] 网页可检索、修改、归档和恢复网页 / 划线 / 笔记；手机可在网页回看，不承诺原生采集。
- [ ] 本地未上传、已确认与冲突资料分别可见；游标过期支持重新取得同步基线。
- [ ] 分页读取与必要索引；用户可导出全部数据和备份，服务端密钥不下发给 content script。

**完成标准**：两个独立客户端通过同一 API 取回资料；离线改动、重复操作、同时改同一批注、设备撤销、服务不可用均不会无声覆盖或丢失内容。结构化资料权威来源只有 D1，避免以 OSS 的第二份目录反向覆盖它。

## R4 · Obsidian 自动同步

**产出**：小型配套插件，默认只读 API 并写入本地 `SelfHub/Clippings/`。

- [ ] 启动、手动和应用运行期间的定时增量同步，记录最近结果和失败原因。
- [ ] 按 pageId 聚合，annotationId 识别段落；标题变化不创建副本。
- [ ] 系统管理区和用户自由区隔离，管理区被人工修改时生成冲突提示 / 副本。
- [ ] 一条划线的修改、删除与归档可以正确更新，重复拉取不重复追加。
- [ ] 文件成功写入后才推进本地游标；应用关闭后重新打开可补齐变更。
- [ ] 与现有五彩目录隔离；Remotely Save 继续处理本地生成的文件，不直接改它的远端格式。
- [ ] 设备授权、保密内容排除、人工导出兜底和取消同步后保留文件的行为明确。

**完成标准**：浏览器新增 / 修改批注后，Obsidian 开启时可取回并落盘；个人自由段落保持不变；错权限、离线、写文件失败和重启都不造成错误游标或重复文件。只存在“导出 Markdown”按钮不能关闭本阶段。

## R5 · 完整迁移与日常切换

- [ ] 对五彩和 GoTab 的真实导出做全量预览及导入，保留原文件和差异报告。
- [ ] 五彩页面 / 划线 / 批注 / 标签等数量有来源说明；未支持字段、重复候选与失锚项可检索。
- [ ] 新系统在空环境从外部完整备份恢复，检查正文、导航、批注和所需附件。
- [ ] 用真实常用站点走通连续 7 个实际使用日；记录新增、修改、重开、搜索和 Obsidian 同步结果。
- [ ] 用独立浏览器配置验证新标签页，保留旧配置中的原工具数据；切换默认入口由用户操作。
- [ ] 确认插件卸载会影响哪些本地数据，卸载前外部备份和服务端同步可验证。

**GoTab 替代就绪**：常用导航、分组 / 文件夹、搜索与排序已迁入，离线和重启可用，备份能恢复。

**五彩替代就绪**：支持范围内可原页划线与批注，刷新能恢复或准确报告失锚，集中搜索能找到，真实 Obsidian 增量同步通过，旧数据不再只存在五彩账号中。

订阅和卸载由用户决定。停止续费不代表必须立刻删除账号或卸载旧工具；迁移以备份与实际使用验收为依据。

## R6 · 后续扩展

- 网页正文剪藏与稍后读：从用户已打开页面提取，记录不完整资源；不只保存 URL 后宣称全文离线可用。
- 图片、截图和 PDF：先原件保存与预览，再独立实现 PDF 文本层 / 页码锚点与标注。
- 手机 / 微信入口：先网页粘贴与回看，再评估系统分享入口；不依赖桌面扩展直接覆盖移动浏览器。
- Safari / Firefox、两种扩展构建、更多站点与附件格式单独验收。
- AI 摘要、标签、相关资料与复习视图使用用户自选服务，关闭后不影响基础保存和搜索。

## 最小发布与验证要求

每阶段产出可独立演示、可导出、可回退的小版本。扩展包检查 Manifest V3 的本地脚本、CSP、权限和依赖；API 覆盖鉴权、分页、幂等和冲突；Obsidian 使用临时库验收写入；原型与功能提交都运行对应构建和必要测试。

本轮为文档变更，只验证 Markdown 链接、差异和规划一致性。接下来真正实施从 R0 的资料准备与 R1 的底座 / 原型开始。
