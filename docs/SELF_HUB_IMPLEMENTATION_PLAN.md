## 1. 开发约定

- 一张任务单只交付一个能验收的结果。任务完成时记录提交版本、测试命令、通过结果和未解决限制。
- 文中路径为实施定位建议；旧组件先适配复用，避免界面和底座同时全量重写。
- 阶段内按依赖推进，先交一条完整用户路径，再横向铺开同类页面。
- 每个阶段做一次正式验收；未完成的功能写明状态，不靠修改 README 宣布完成。
- 本文全部任务为待办，勾选需对应实际代码及验证证据。

## 5. P3：可选多端同步和 Obsidian 子项目

P3 不与 P1/P2 同时开工，先按真实需求确认部署成本与同步边界。

| 任务 | 交付 | 验收 |
| --- | --- | --- |
| P3-01 服务端协议与认证评审 | 数据库 schema、操作协议、配对和撤销、附件权限 | 认证与领域版本规则无歧义，Token 与页面访问门禁分开 |
| P3-02 同步服务 | bootstrap、operations、changes、幂等和保留策略 | 重复请求不重复写；冲突返回明确结果；事务与游标正确 |
| P3-03 网页/扩展客户端 | outbox、增量拉取、冲突中心、断网恢复 | 两个独立设备离线改同条记录不会无声覆盖 |
| P3-04 Obsidian 插件 | 管理区写入、自由区保护、游标与失败恢复 | 新增/修改/删除可跟进，重拉无重复，写失败不推进游标 |
| P3-05 真实迁移与切换 | 五彩/GoTab 实际导出映射、数量报告、最终备份 | 连续实际使用验证；原始备份可取回；未支持字段不丢失 |
